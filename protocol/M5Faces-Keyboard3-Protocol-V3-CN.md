# M5Faces-Keyboard3 控制协议（固件 v03）

---

## 1. 硬件接口

| 项目 | 说明 |
| :--- | :--- |
| I2C 从机地址（7 位） | `0x08` |
| 通信速率 | Standard 100 kbps / Fast 400 kbps |
| IRQ 引脚状态 | 低电平：有新数据；高电平：空闲 |

### 1.1 IRQ 时序说明

当有新的按键数据产生时，`IRQ` 会被拉低；主机把数据读取完成后，`IRQ` 恢复为高电平。

```text
按键按下                  主机读取完成
   │                           │
───┘ IRQ 低电平(0) ─────────────┘ IRQ 高电平(1)
```

---

## 2. 工作模式

模块上电后默认进入 **Normal 模式**。  
主机可以通过指令 `0xF0` 切换工作模式。

| 模式 | 值 | 说明 |
| :--- | :--- | :--- |
| Normal | `0x00` | 固件完成按键映射，每次 IRQ 读取 **1 字节 ASCII** |
| Direct | `0x01` | 直接输出原始按键矩阵数据，每次 IRQ 读取 **固定 10 字节** |

> **注意：**
> 每次切换模式时，固件都会自动清空矩阵历史状态缓存。

---

## 3. 寄存器地址映射

| 寄存器地址 | 可读 | 可写 | 说明 |
| :--- | :--: | :--: | :--- |
| `0xD0` | ✓ | ✗ | 设备类型 ID |
| `0xE0~0xEB` | ✓ | ✗ | 96-bit UID，按芯片 UID 存储地址从低到高排列，共 12 bytes |
| `0xF0` | ✓ | ✓ | 操作模式（Normal / Direct） |
| `0xF1` | ✓ | ✓ | LED 模式 |
| `0xFE` | ✓ | ✗ | 固件版本号 |
| `0xFF` | ✓ | ✓ | I²C 地址寄存器 |

---

## 4. 写操作（主机写入）

写入格式为：`[寄存器地址] [数据]`，总长度固定为 **2 字节**。

| 寄存器地址 | 数据 | 功能 |
| :--- | :--- | :--- |
| `0xF0` | `0x00` | 切换至 Normal 模式 |
| `0xF0` | `0x01` | 切换至 Direct 模式 |
| `0xF1` | `0x00`–`0xFF` | 设置 LED 模式（详见第 8 节） |
| `0xFF` | 有效地址范围内的值 | 修改模块 I²C 地址，并立即生效（范围见第 4.1 节） |

### 4.1 I²C 地址说明

向 `0xFF` 写入新地址后，配置会立即生效。该操作耗时约 `20 ms`，且掉电后不会丢失。  

请确保写入的地址值处于系统允许的有效 I²C 地址范围内。

---

## 5. 读操作（主机读取）

### 5.1 读取流程

1. 主机先写入 **1 字节寄存器地址**
2. 随后发起 **I²C 读取**
3. 模块从该寄存器地址开始按顺序返回数据

### 5.2 支持读取的寄存器段

#### 段 A：设备类型 ID

| 起始地址 | 可读字节数 | 返回内容 |
| :--- | :---: | :--- |
| `0xD0` | 1 | `[device_id]` |

#### 段 B：UID

| 起始地址 | 最大可读字节数 | 返回内容 |
| :--- | :---: | :--- |
| `0xE0~0xEB` | `0xEC - 起始地址` | 从对应偏移开始的 UID 剩余数据 |

UID 在设备上电时读取到缓存。主机可从 `0xE0~0xEB` 任一地址开始，按需读取不超过该地址到 `0xEB` 的剩余字节。

#### 段 C：操作模式 + LED 模式

| 起始地址 | 可读字节数 | 返回内容 |
| :--- | :---: | :--- |
| `0xF0` | 2 | `[operation_mode, led_mode]` |
| `0xF1` | 1 | `[led_mode]` |

#### 段 D：固件版本号 + I²C 地址

| 起始地址 | 可读字节数 | 返回内容 |
| :--- | :---: | :--- |
| `0xFE` | 2 | `[firmware_version, i2c_addr_reg]` |
| `0xFF` | 1 | `[i2c_addr_reg]` |

## 6. Normal 模式说明

在 **Normal 模式** 下，固件会完成按键映射，主机每次读取的是按键对应的 **ASCII 数据**。

### 6.1 修饰键优先级

如果多个修饰键同时有效，按以下优先级决定输出结果（从高到低）：

```text
ALT > SYM > FN > aA > 默认
```

对应映射关系如下：

| 修饰键状态 | 使用的映射列 |
| :--- | :--- |
| 无修饰键 | `KeyMap[n][0]`（小写 / 默认） |
| `aA` | `KeyMap[n][1]`（大写） |
| `SYM` | `KeyMap[n][2]`（符号） |
| `FN` | `KeyMap[n][3]`（扩展功能） |
| `ALT` | `KeyMap[n][4]`（144–178） |

### 6.2 `Enter` 键的特殊处理

`Enter` 键不会直接查 `KeyMap`，而是固定输出：

- 第一次读取返回：`0x0D`（`\r`）
- 第二次读取返回：`0x0A`（`\n`）

也就是说，按一次 `Enter` 会产生 **1 次 IRQ**，主机需要连续读取两次；两次读取完成后，中断才会清除。

> **注意：**
> 虽然 Normal 模式通常描述为“每次 IRQ 读取 1 字节 ASCII”，但 `Enter` 键是一个特殊例外，需要连续读取两次。

---

## 7. Direct 模式说明

在 **Direct 模式** 下，模块直接输出原始按键矩阵数据。

### 7.1 触发条件

只要任意按键状态发生变化，`IRQ` 就会拉低。  
主机每次都需要读取 **固定 10 字节** 数据。

### 7.2 数据包格式

| 偏移 | 内容 |
| :--- | :--- |
| Byte 0 | 数据长度，固定为 `0x0A`（10） |
| Byte 1–2 | 矩阵行 0（`OUTPUT_MODE_1`） |
| Byte 3–4 | 矩阵行 1（`OUTPUT_MODE_2`） |
| Byte 5–6 | 矩阵行 2（`OUTPUT_MODE_3`） |
| Byte 7–8 | 修饰键行 |
| Byte 9 | 校验和 |

### 7.3 每组 2 字节的格式

```text
高字节（Byte N）:
  Bit 7   : 变化标志（1 = 本次数据与上次不同）
  Bit 6–4 : 行索引（0–3）
  Bit 1–0 : GPIOA IDR Bit 9–8（PA9, PA8）

低字节（Byte N+1）:
  Bit 7–0 : GPIOA IDR Bit 7–0（PA7–PA0）
```

### 7.4 10 位原始值的组合方式

```c
raw = ((high_byte & 0x03) << 8) | low_byte;
```

> **电平规则：**
>
> - `0` = 按下
> - `1` = 未按下
>
> 这是因为按键输入使用了上拉。

### 7.5 修饰键行说明

| Bit | 按键 |
| :--- | :--- |
| 0 | `aA` |
| 1 | `ALT` |
| 2 | `Enter` |
| 3 | `SYM` |
| 4 | `FN` |
| 5–7 | 保留，固定为 `1` |

## 8. LED 灯效控制（指令 `0xF1`）

### 8.1 预设灯效模式（`0x00`–`0x08`）

| 值 | 触发场景 | 灯效说明 |
| :--- | :--- | :--- |
| `0` | 无修饰键 | 两个灯都灭 |
| `1` | `aA` 单击 | 左灯常亮 |
| `2` | `aA` 双击锁定 | 左灯慢闪（500 ms） |
| `3` | `ALT` 激活 | 左灯快闪（150 ms） |
| `4` | `FN` 单击 | 右灯常亮 |
| `5` | `FN` 双击锁定 | 右灯慢闪（500 ms） |
| `6` | `SYM` 双击锁定 | 右灯快闪（150 ms） |
| `7` | `SYM` 单击 | 左右交替慢闪（500 ms） |
| `8` | 外部设置 | 左右交替快闪（200 ms） |

### 8.2 手动控制模式（Bit 7 = 1）

当参数的 Bit 7 为 `1` 时，表示进入手动位控制模式。

#### 位定义

| Bit | 功能 |
| :--- | :--- |
| 7 | 必须为 `1` |
| 4 | `1` = 左灯亮 |
| 5 | `1` = 右灯亮 |
| 其余位 | 保留 |

#### 常用示例

| 发送值 | 效果 |
| :--- | :--- |
| `0x80` | 左右都灭 |
| `0x90` | 左亮，右灭 |
| `0xA0` | 左灭，右亮 |
| `0xB0` | 左右都亮 |

## 9. 修饰键逻辑（Normal 模式）

### 9.1 `aA` / `FN` / `SYM` 的状态切换规则

这 3 个按键都使用相同的状态机：

```text
状态 0（关闭）
  │ 单击
  ▼
状态 1（单次生效）── 按下普通键后 ──→ 自动回到状态 0
  │ 再次单击
  ▼
状态 2（锁定）
  │ 再次单击
  ▼
状态 0
```

简单理解如下：

- **单击一次**：只对下一次普通按键生效
- **快速双击**：进入锁定状态
- **锁定后再按一次**：关闭

> `ALT` 不走这个逻辑。  
> `ALT` 是瞬时键：按下时生效，松开后立即失效，不支持双击锁定。

### 9.2 修饰键互斥规则

任意一个修饰键生效时，其他修饰键都会被清零。  
也就是说，同一时刻只允许一个修饰键处于激活状态。

## 11. 备注

- Normal 模式适用于主机直接读取字符
- Direct 模式适用于主机自行处理矩阵扫描结果
- 若主机需要兼容 `Enter` 键，请特别处理其 **两次读取** 行为
- 若需要稳定处理中断，请严格按照 `IRQ` 拉低后读取、读取完成后等待恢复高电平的方式进行通信
